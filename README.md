# graphowl-landing

Source of the product page at <https://graphowl.app> (Astro, one page). The documentation lives in [`graphowl/docs`](https://github.com/graphowl/docs) and is served under `/docs`.

```bash
npm install
npm run dev
./publish.sh      # builds and copies into ../graphowl-site; commit and push that repository
```

Every number and claim on the page is checked against the product (101 MCP tools, 469 API operations); no benchmark figures appear until a method is published.
